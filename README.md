# Бот для приёма заявок (Telegram и MAX)

Бот для салона, мастера или небольшого бизнеса: показывает услуги, цены и контакты, принимает заявки и сразу пересылает их владельцу. Две версии с одинаковыми функциями: для Telegram и для MAX.

## Возможности
- Меню с кнопками: услуги, цены, контакты, часы работы
- Анкета: имя → телефон (с проверкой) → выбор услуги кнопкой
- Кнопка «Отмена» на любом шаге
- Заявка сразу приходит владельцу
- Все заявки сохраняются в таблицу (открывается в Excel), выгрузка командой /zayavki
- Бот не падает, если отправка сообщения не удалась

## Технологии
Python 3.13, aiogram 3 (Telegram), maxapi (MAX), FSM (машина состояний), CSV

## Запуск
1. `python -m venv venv` и активировать окружение
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env` и заполнить переменные
4. Telegram: `python bot.py`, MAX: `python max_bot.py`

Бота для MAX нужно создать на платформе MAX для партнёров (business.max.ru) и получить там токен.
