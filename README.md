# Бот для приёма заявок (Telegram)

Бот для салона, мастера или небольшого бизнеса: показывает услуги, цены и контакты, принимает заявки и сразу пересылает их владельцу.

## Возможности
- Меню с кнопками: услуги, цены, контакты, часы работы
- Анкета: имя → телефон (с проверкой) → выбор услуги кнопкой
- Кнопка «Отмена» на любом шаге
- Заявка сразу приходит владельцу в Telegram
- Все заявки сохраняются в таблицу (открывается в Excel), выгрузка командой /zayavki
- Бот не падает, если отправка сообщения не удалась

## Технологии
Python 3.13, aiogram 3, FSM (машина состояний), CSV

## Запуск
1. `python -m venv venv` и активировать окружение
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env`, вписать токен бота и свой Telegram ID
4. `python bot.py`
